# neko-forum-client

Cliente mínimo para https://fr.neko-void-linux.online/ con wry + tao.
Linux: Debian/Ubuntu `libwebkit2gtk-4.1-dev libgtk-3-dev pkg-config`; Arch `webkit2gtk-4.1 gtk3`; Void `libwebkit2gtk41-devel gtk+3-devel pkg-config`.
Compilar: `cargo build --release`; binario: `target/release/neko-forum-client`.
